本目录已经完成真实 API、真实 A/B、截图和 PDF；正式提交前只需补身份与发布链接。


团队、学校、负责人和联系方式已由参赛者确认；PDF 目前只保留仓库 URL 和视频 URL 两项待填写字段。

## 提交前必须填写

- 公开 GitHub/Gitee URL；
- 真实演示视频 URL；
- 组委会要求的其他身份字段。

正式稿已在 v3.0.0-rc3 统一重排为 A4 评审版。若填写身份字段后需要重建：先执行 `pip install -r requirements-docs.txt` 与 `python scripts/build_submission_html.py`，再用 Chrome/Edge 将 `tmp/submission_pdf_html/` 中三份 HTML 打印为 A4 PDF，并逐页检查断行、表格和页尾。

## 离线示例成果

`离线示例成果_仅演示/` 仅用于无 AK 演示和断网容灾，所有结果都必须保持“模拟”标识，不能进入正式真实结论。
