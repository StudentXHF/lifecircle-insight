# 圈析智图｜约 4 分 30 秒演示视频逐字稿与操作清单

> 本稿按当前 v3.0.0-rc3 界面编写。方括号中的文字只做操作，不朗读；“照念”后的文字可以直接念。正式录制优先打开已经恢复的真实历史记录，不重新运行地图分析，避免重复消耗百度 API 配额。

## 一、启动后怎么操作

1. 双击项目根目录的 `start.bat`，保持黑色终端窗口开启，不要关闭。
2. 浏览器打开 `http://127.0.0.1:8015`。
3. 如果网页已经能打开，不要重复双击 `start.bat`。
4. 左侧历史记录应能看到：
   - `#4 徐家汇街道级样例 · 真实 · 100分`
   - `#3 张江镇街道级样例 · 真实 · 42.7分`
5. 正式录制时先点击 `#3 张江镇街道级样例`，不要点击“地址转坐标”和“开始体检”。打开历史记录不会重新调用 Place、RouteMatrix 或 DirectionLite。

## 二、演示参数

点击张江镇历史记录后，表单会自动恢复以下参数：

| 字段 | 值 |
|---|---|
| 模式 | 真实百度 API |
| 地址（仅用于说明） | 上海市浦东新区张江镇人民政府 |
| 中心点名称 | 张江镇街道级样例 |
| 城市 | 上海市 |
| 经度 | 121.620868 |
| 纬度 | 31.211058 |
| 坐标系 | BD09LL（百度） |
| 步行阈值 | 15 分钟 |
| 扇形采样方向数 | 16 |
| POI 检索半径 | 1800 米 |

这些值用于向评委说明输入能力。正式录制不要再次点击“地址转坐标”或“开始体检”。

## 三、录制前准备

- 浏览器保留三个标签页：本地工作台、GitHub 仓库、GitHub Actions 成功页。
- 关闭微信、QQ、邮箱和系统通知。
- 不打开 `.env`，不展示任何 AK 或模型密钥。
- 1920×1080 录制时浏览器缩放使用 90% 或 100%，以能完整看到结果卡片为准。
- 先试播一次麦克风，确认声音清楚、不过载。
- AI 解读可能需要十几秒；录制时可以等待并继续解说，后期也可以剪掉多余等待。

## 四、逐字讲稿

### 0:00 - 0:20｜开场

**[操作]** 浏览器显示圈析智图首页和项目标题，不操作。

**[照念]**

> 大家好，我们是来自电子科技大学的经纬智析团队，我是负责人徐海峰。我们的参赛作品是“圈析智图”，一款基于百度地图开放能力的十五分钟生活圈智能体检与规划助手。

### 0:20 - 0:45｜问题与方案

**[操作]** 缓慢向下滚动到分析参数区。

**[照念]**

> 十五分钟生活圈常被简单表示成一个固定半径圆，但真实城市中存在道路绕行、河道、围墙、路口和不同出入口。同样的直线距离，实际步行时间可能完全不同。圈析智图把“离得近”升级为“真实路网下走得到”，并进一步检查民生设施覆盖和服务盲区。

### 0:45 - 1:10｜真实输入与参数

**[操作]** 点击左侧 `#3 张江镇街道级样例`；短暂停留在自动恢复的表单，鼠标依次指向“真实百度 API”、经纬度、15 分钟、16 个方向和 1800 米。

**[照念]**

> 这里展示张江镇街道级真实样例。系统支持输入上海地址并转换为百度 BD09 坐标。本次使用十五分钟阈值、十六个采样方向和一千八百米 POI 检索半径。为避免重复消耗接口额度，视频直接打开已经由真实百度 API 生成并保存的历史结果。

### 1:10 - 1:45｜真实城市 3D

**[操作]** 滚动到“城市空间可视化中枢”，点击“真实城市 3D”，等待底图加载；点击“进入沉浸演示”，再点击“自动环绕”，展示约 3 秒后再次点击停止。

**[照念]**

> 这是百度 JSAPI GL WebGL 真实城市底图。蓝色区域是由真实步行路网测时和空间插值得到的十五分钟等时边界；五百米和一公里参考圈提供距离尺度；设施、盲区和路网探针直接叠加在真实城市空间中。这里的真实底图与分析覆盖物来源明确，不把离线生成的楼体冒充真实 BIM。

**[操作]** 退出沉浸演示。

### 1:45 - 2:10｜核心算法与热力图

**[操作]** 点击“分析热力图”，让采样点和不规则边界完整显示。

**[照念]**

> 核心并不是三维效果，而是可解释的计算过程。系统默认在十六个方向设置四个距离层级，共形成六十四条步行路线探针，通过 RouteMatrix 批量测时。对局部非单调耗时使用保守单调包络，再对九百秒阈值插值，同时记录有效方向、纠正次数、截断和外推情况。

### 2:10 - 2:40｜设施覆盖与盲区

**[操作]** 向下滚动到设施覆盖、规划建议和服务盲区区域；鼠标指向张江镇的体检分、置信度和盲区数量。

**[照念]**

> 张江镇样例的数据置信度为百分之百，十五分钟等时圈面积约一点六零八平方公里，共检索到五十五个圈内设施，体检分四十二点七，并识别出四个服务盲区。系统覆盖基础医疗、小学、菜市场、药店、超市和养老服务六类设施。如果某一类接口失败，会标记为待核验，而不会把接口失败错误解释为现实中没有设施。

### 2:40 - 3:00｜真实路网价值

**[操作]** 停留在“路网差异诊断”和“算法质量诊断”。

**[照念]**

> 为了量化真实路网的价值，系统同时给出直线步行基线、等时圈面积比、路径绕行系数和时间惩罚系数。张江镇的等时圈与直线圆面积比为零点四三九，路径绕行系数约为一点三九，说明只画几何圆会明显高估实际可达空间。

### 3:00 - 3:22｜AI 规划解读

**[操作]** 点击“生成解读”。等待时继续朗读；生成后缓慢滚动展示文字。

**[照念]**

> 在确定性空间分析完成后，还可以调用模型生成规划解读。模型只接收后端筛选后的分数、覆盖、盲区和质量证据，不接收地图密钥、中心坐标或 POI 名称，也不参与等时圈、评分和盲区计算。因此模型不可用时，核心分析仍然可以独立运行。

### 3:22 - 3:40｜工程证据与导出

**[操作]** 展示 API 调用与配额区域，再滚动到“成果导出”；鼠标依次划过 Markdown、HTML、CSV、JSON、GeoJSON 和 ZIP。可以点击一次“ZIP 交付包”，看到浏览器开始下载即可。

**[照念]**

> 工程上，系统区分 HTTP 请求数和路线配额单元，支持有界并发、重试、超时，以及内存和 SQLite 缓存。每次体检都能导出 Markdown、独立 HTML、两类 CSV、JSON、GeoJSON 和完整 ZIP，不只交付一张截图，而是交付可复核、可继续进入 GIS 的结构化成果。

### 3:40 - 4:05｜真实 A/B 对比

**[操作]** 点击左侧 `#4 徐家汇街道级样例`，停留在顶部 KPI 和设施覆盖；再让画面同时能看到左侧两个真实历史记录。

**[照念]**

> 使用完全相同的参数，徐家汇街道级样例得到二点零八八平方公里的十五分钟等时圈，共有一百九十个圈内设施，体检分一百分，服务盲区为零。相比之下，张江镇样例只有五十五个圈内设施并出现四个盲区。这个对比说明工具能够识别不同城市片区在步行可达性和公共服务覆盖上的差异。

### 4:05 - 4:25｜开源与质量保障

**[操作]** 切换到 `https://github.com/StudentXHF/lifecircle-insight`，展示 README；再切换 Actions 页面，指向绿色成功标记。

**[照念]**

> 项目已经在 GitHub 公开，采用 MIT 许可证，提供 Windows 一键启动、Docker、完整测试、贡献指南和 CI。当前三十五项自动化测试全部通过，服务端密钥、本地数据库和运行缓存都不会进入公开仓库。

### 4:25 - 4:38｜结尾

**[操作]** 回到项目首页或真实地图画面。

**[照念]**

> 圈析智图不是把一个圆画得更漂亮，而是把真实路网、设施覆盖、可靠性判断和可复核交付整合成普通电脑即可运行的开源社区体检工具。感谢各位老师观看。

## 五、录制完成后的检查

- 总时长建议控制在 4 分 10 秒至 4 分 50 秒。
- 从头到尾完整播放一遍，确认人声、画面和鼠标操作同步。
- 确认没有录到 `.env`、AK、模型密钥、私人聊天或通知。
- 确认张江镇和徐家汇均明确称为“街道级样例”，不夸大为法定规划结论。
- 导出为 H.264 + AAC 的 MP4，命名为 `lifecircle-insight-demo.mp4`。
- 建议保存到 `圈析智图_准提交材料/视频/`，再上传 GitHub Release。
