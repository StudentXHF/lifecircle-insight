```text

style_check: OK
compileall: OK
JavaScript syntax: OK
```

pytest 仍报告 2 条来自 FastAPI/Starlette 第三方 TestClient 的弃用警告，不影响运行结果，未通过屏蔽警告伪造“静默全绿”。
