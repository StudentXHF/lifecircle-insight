## 2. 百度地图命题依据

项目技术开发的直接任务书为仓库：

```text
docs/赛题任务书_原始.pdf
```

任务书标题：

**【开源 AI 工具赛道】基于地图开放能力的“15 分钟生活圈”智能体检与规划助手**

明确要求：

- 使用百度地图开放能力，包括但不限于地理编码/逆地理编码、POI、路径规划与距离计算；
- 选择城市任意社区/街道样例；
- 基于真实路网计算 15 分钟步行等时圈；
- 统计民生设施覆盖；
- 输出可视化体检报告；
- 标注设施匮乏的灰色区域；
- 交付开源源码、构建/自动测试脚本、技术设计和真实对比测试报告。

评分权重：

- 功能正确性与覆盖率：40%
- API 深度调用与工程优化：30%
- 产品交互与用户体验：15%
- 开源工程规范：15%

## 3. 当前公开页与任务书的状态差异

截至 2026-09-14，官网首页“企业赛题”区域仍显示“筹备中 / 即将上线”，但用户已经取得明确的百度地图命题任务书，且 OSCHINA 新闻列表也出现“上海开源大赛百度地图命题公布”相关公告。

因此本项目采用如下原则：

1. **技术实现以已取得的具体命题任务书为直接依据。**
2. 报名入口中最终是否已可选该命题、命题编号、企业命题附加字段，以用户登录后的报名系统/确认邮件为准。
3. 不把当前公开首页“筹备中”自行解释为命题无效，也不把任务书来源扩展成官网未明确写出的提交字段。

## 4. 百度地图官方接口依据

已核验官方文档：

- RouteMatrix / 批量算路：https://lbsyun.baidu.com/docs/webapi?title=routematrix%2Froutchtout
- 步行批量算路：https://lbsyun.baidu.com/docs/webapi?title=routematrix%2Froutchtout-walk
- Place 圆形区域检索：https://lbsyun.baidu.com/docs/webapi?title=placev2%2Fguide%2Fwebservice-placeapi%2Fcircle

2026-09-14 复核的官方文档（页面更新时间为 2026-03-19 / 2026-03-24）明确：

- 步行/骑行批量算路单次最多计算 50 条路线；
- RouteMatrix 配额/并发按最终路线数计算，而非 HTTP 请求数；
- Place 圆形检索可以指定中心点和半径，支持 `radius_limit` 严格范围约束；
- Place 多关键字并集可使用 `$` 分隔（最多 10 个关键字，具体以官方最新文档为准）。

这些事实已经进入 v3.0.0-rc3 的算法和统计设计。
