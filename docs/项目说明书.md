# 圈析智图｜项目说明书 v3.0 RC

## 一、项目定位

**圈析智图（LifeCircle Insight）**是一款面向社区公共服务初筛与规划诊断的轻量 Web 工具。它以百度地图开放能力作为路网与 POI 计算引擎，用“真实步行时间可达性”替代简单直线半径，以低门槛方式生成近似 15 分钟生活圈、设施覆盖、服务盲区和可解释规划建议。

## 二、问题与价值

传统生活圈粗评常直接用圆形缓冲区判断覆盖，但现实步行受到道路绕行、河道、围墙、路口、桥梁等影响。同样 1000 米直线距离，实际步行距离和耗时可能差异明显。

项目提供三层价值：

1. **从“距离”升级到“时间”**：以步行路网耗时判断可达性。
2. **从“有无 POI”升级到“覆盖 + 盲区”**：不仅统计圈内设施，也查找关键服务缺口位置。
3. **从“黑箱图形”升级到“可追溯证据”**：展示采样点、API 调用统计、算法质量和数据置信度，可导出结构化成果。

## 三、核心用户

- 社区/街道规划和公共服务调研人员
- 城市更新、空间规划、地理信息研究人员
- 高校规划/GIS/数据科学课程与竞赛团队
- 商业服务选址和公共服务初筛人员

## 四、核心流程

```text
地址/中心坐标
  -> 坐标标准化
  -> 多方向多半径扇形采样
  -> RouteMatrix Walking 批量测时
  -> 单调包络 + 阈值插值
  -> 15分钟近似等时圈
  -> Place 多类别、多页 POI 检索
  -> 覆盖统计 / 盲区识别
  -> DirectionLite 代表性路径
  -> 路网差异诊断 / 数据置信度
  -> 规划建议
  -> MD / HTML / CSV / JSON / GeoJSON / ZIP
```

## 五、核心功能

1. 坐标输入：BD09LL / GCJ02 / WGS84。
2. 地址转坐标：真实模式调用地理编码。
3. 15 分钟等时圈：默认 16 方向 × 4 半径。
4. 设施覆盖：基础医疗、小学、菜市场、药店、超市、养老服务。
5. 服务盲区：圈内网格点 1 km 邻近缺少菜市场/药店/小学。
6. 空间可视化：真实百度 WebGL 城市 3D、数字孪生表达、分析热力图，叠加等时圈、500m/1km 尺度圈、POI、盲区与路网探针。
7. 直线圆 vs 路网可达：面积比、绕行系数、时间惩罚系数。
8. 算法质量诊断：有效样本率、单调纠正、截断方向、外推方向。
9. 数据置信度：将算路成功率与已知设施类别权重合并展示。
10. 历史记录、多格式导出与一键沉浸演示模式。

## 六、技术创新点

### 6.1 不获取底层路网的 API 测时等时圈

不要求本地保存道路图，而是把地图平台视为“路网函数”。对周边分散点调用真实步行测时，再在角度方向上插值，符合赛题鼓励的扇形采样/空间插值路径。

### 6.2 保守单调包络提升插值稳定性

真实算路在少量相邻半径上可能因绑路、入口位置等出现“更远样点耗时反而更短”的局部非单调现象。直接线性插值会造成边界尖刺。项目在单一方位内先做累计最大耗时包络，再寻找 15 分钟阈值，保留纠正计数作为质量诊断，不静默掩盖。

### 6.3 API 配额与 HTTP 请求分开统计

RouteMatrix 的计费/配额逻辑按最终路线数，而不是 HTTP 次数。64 条默认路线虽然只需两个 HTTP 批次，但统计区会单独显示“配额单元估算”，避免把工程优化错误宣传成配额只消耗 2 次。

### 6.4 “未知”不等于“缺失”

某一 Place 类别因配额或网络失败时，该类别进入 `unknown`；不按 0 分处理，也不据此生成服务盲区，避免在数据不完整时做确定性错误判断。

### 6.5 多层交付证据

除视觉页面外，提供 Markdown/HTML 报告、CSV、JSON 和 GeoJSON，便于评委核验算法输入输出和后续 GIS 使用。


### 6.6 三层空间可视化兼顾真实性与演示效果

- **真实城市 3D**：百度 JSAPI GL WebGL 真实城市底图，采用官方异步回调加载、倾斜/旋转视角并叠加 500m、1km、15min 等时圈、POI、盲区和测时探针；可选个性化 Style ID。
- **数字孪生表达**：在无浏览器 AK 时，以 Canvas 表达道路、楼体、绿化和分析结果；明确声明不是实际 BIM/地籍。
- **分析热力图**：保留确定性分析视图，承担算法解释与证据展示。

结果页将地图主舞台置于全宽区域，并提供沉浸演示模式，以减少旧版并列卡片造成的空间拥挤，同时不牺牲真实性边界。

## 七、工程性

- FastAPI + SQLite，部署轻量。
- 原生前端，无 Node.js 构建链。
- 服务端 `BAIDU_MAP_AK` 不进入浏览器；JSAPI 使用独立 `BAIDU_MAP_BROWSER_AK` 并建议配置 Referer 白名单。
- 并发上限、重试、超时。
- 内存 + SQLite TTL API 缓存。
- 自动化测试、GitHub Actions、Docker、一键启动。
- MIT License、贡献指南、安全策略、治理与路线图。

## 八、产品边界

本项目是规划筛查工具，不是政府正式规划审查系统。项目没有人口密度、用地权属、设施容量、步行无障碍等级、政策红线等数据，因此规划建议必须进一步结合公开规划资料与现场调研。

## 九、验证与公开成果

项目已完成百度地图 API 权限检查、两个上海真实样例对比、真实 WebGL 地图验证、35 项自动化测试与七类成果导出。公开代码仓库、作品介绍和演示视频均提供稳定访问入口，真实测试的 Markdown、CSV 与 JSON 证据保存在 `docs/` 目录中。
