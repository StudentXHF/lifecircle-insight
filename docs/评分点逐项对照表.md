## 答辩时主动说明的诚信边界

1. 等时圈是路网 API 离散测时后的近似插值，不是底层道路图洪泛。
2. “体检分”和“数据置信度”是项目内部解释指标，不是官方评价分。
3. POI API 失败时标记 unknown，不把接口失败说成现实服务缺失。
4. 离线示例只用于无 AK 演示，真实对比报告必须由真实百度 API 生成。
5. 真实城市 3D 使用百度 WebGL 底图；Canvas 数字孪生楼体属于表达层，不是实际 BIM。
