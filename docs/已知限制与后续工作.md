## 二、仍然真实存在的限制

1. **等时圈是离散路网测时后的空间插值近似**，不是持有底层路网拓扑后的洪泛等时面。
2. POI 召回受百度地图数据质量、关键词、权限和配额影响。
3. 设施数量不等于设施容量、质量、人口需求或服务等级。
4. 当前盲区以离散采样点为主，尚未聚类成官方规划意义的连续缺口面。
5. “真实城市 3D”基于百度 JSAPI GL WebGL；三维楼块/精模的丰富度依赖目标区域的百度数据覆盖、缩放级别和浏览器 GPU，不能保证所有上海社区都呈现同等高楼效果。
6. Canvas 数字孪生是增强表达层，不是实际 BIM、地籍、倾斜摄影或实景重建。
7. 未接入人口栅格、街道法定边界、设施容量、无障碍网络和用地约束。
8. 真实模式依赖合法有效且具备相应服务权限的百度地图服务端 AK 与浏览器端 AK；平台权限、配额或网络异常会影响数据获取。

## 三、三维技术选型

百度 JSAPI Three 可以进一步提供 Three.js 三维场景、楼块、精模、倾斜摄影和环境效果，但会引入额外 NPM / Three.js 构建链和新的真实三维数据依赖。

当前版本优先保证：

- Python 单环境可快速复现；
- 真实百度 WebGL 城市底图；
- 地图 API 深度调用和空间算法可解释性；
- 真实社区结果可复核。

因此 v3.0 将 JSAPI Three 留作增强路线，避免为了视觉效果牺牲稳定性。当前 JSAPI GL 已在张江镇真实记录上完成浏览器验收；若其他区域三维建筑覆盖不足，可再评估独立增强分支，不影响主分析流程。
